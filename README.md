# Controle de Materiais

Projeto full stack para controle de materiais, estoque e movimentações entre unidades.

## Stack

### Backend
- C#
- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- xUnit

### Frontend
- React
- TypeScript
- Vite
